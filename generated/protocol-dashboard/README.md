# protocol-dashboard

Live protocol dashboard aggregating device and protocol data

Generated by the **view/php-standalone** target of Service Factory.
Bundle hash: `076dee95064df5ef`.

## Run

```bash
php -S 0.0.0.0:8082 index.php
```

Then open <http://localhost:8082/>. The client polls
`?format=json` every 1000ms and rebuilds the page without a full reload.

## Sources

- **protocol** — `GET http://localhost:8080/api/v3/protocols/123` (refresh: 1s)
- **devices** — `GET http://localhost:8081/api/v3/devices` (refresh: 5s)

## Endpoints

- `GET /`               — HTML page with embedded polling client.
- `GET /?format=json`   — fresh aggregate of every source as JSON.
- `GET /health`         — liveness probe returning `{ "status": "ok" }`.

> Note: this bundle declares a custom template, but the
> `view/php-standalone` generator currently ignores it and
> uses the default card layout. Custom templates will be
> honoured by a future Jinja/Twig-aware generator.
## Notes

- No composer, no framework. PHP 8.0+ is the only requirement.
- CORS is *not* handled here; each upstream service must allow this
  origin if the view is served from a different host/port.
- The generated file is side-effect free at import time; it only
  does work when handling an HTTP request.
